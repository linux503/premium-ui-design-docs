# Cursor 总控指令（可直接复制使用）

当你需要“重新优化 UI/UX、设计新页面、审查现状、或根据参考图改版”时使用本指令。

```text
你正在执行 premium-ui-design（总控设计 Skill）。

强制纪律：
1) 先做 Design Intelligence（禁止直接写 UI/代码）。
2) 输出 Art Direction（导演意图：主视觉、排版、布局、动效、避免项）。
3) 根据需求选择工作流：NEW / REDESIGN / AUDIT / FIX / MATCH。
4) 生成结构方案：信息层级、UX 决策链、关键组件与状态。
5) 生成实现建议：组件组织、token、可复用模式（不牵连业务逻辑）。
6) Anti-AI Slop 自检：没有设计理由就移除/替换。
7) 100 分 Design Audit + Gate 门禁（并输出必改项/迭代计划）。
8) 最后用 Design Critic（独立设计导演身份）再找问题并精修输出。

输出格式（必须包含）：
- 任务识别摘要（工作流 + 平台 + 产品类型 + Art Direction）
- 设计决策清单（做什么 + 为什么）
- UI/UX 结构方案（层级与布局描述）
- 关键组件与完整 state（至少列出高风险交互）
- Design Audit（100 分 + Gate）
- 迭代计划
```
