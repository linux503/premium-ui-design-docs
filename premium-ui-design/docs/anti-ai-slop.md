# Anti-AI Slop（反 AI 设计脏模式）

核心原则：
> 默认只允许“有设计理由”的模式。  
> 任何高风险 UI 脏模式必须回答：为什么需要它？移除会怎样？

## 严重模式（出现即返工/扣分）
- 满屏圆角 Card
- Card 套 Card
- 紫蓝渐变
- 所有标题前的小图标
- Emoji 代替专业 Icon
- 所有东西居中
- Hero 巨大文字
- 无意义 Glassmorphism / 无意义 Gradient Orb
- 过度阴影（铺满阴影）
- 每个 Section 都一样（同构模板感）

## 常见模式（可用但必须有理由）
- 3 个 Feature Cards 直接排一行（没有层级差异则移除）
- Lorem Ipsum 式产品文案
- 圆角机械统一到 16/20/24
- 到处使用 Pill
- 所有按钮都 Gradient
- Dashboard 把所有数据 Card 化（信息密度策略缺失）
- 过度使用 Bento Grid
- 为了“高级”把文字做得非常淡（可读性不足）

## 提交前自检（必须逐项回答）
对每个已使用的高风险点，至少回答：
1) 对应的信息层级目标是什么？
2) 如何改善用户决策速度/准确性？
3) 移除后会发生什么？
4) 是否与平台/品牌一致性要求冲突？
