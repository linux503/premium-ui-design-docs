# Design Intelligence（禁止直接写 UI 的输入冻结）

在任何实现建议之前，先完成以下“情报卡”。Skill 在提示中要求用户确认关键点。

## 必填字段
**Product（产品是什么）**：____  
**Audience（谁使用）**：____  
**Core task（核心任务）**：____  
**Platform（平台）**：Web / iOS / macOS / Android / Flutter / React Native / 其他  
**Brand personality（品牌气质）**：Native / Calm / Precise / Premium / Playful / Technical / 其他  
**Information density（信息密度）**：Low / Medium / High  
**Visual focus（视觉重点）**：____  
**Avoid（不想要）**：____  

## 必填：Art Direction（可执行导演意图）
- Primary visual idea（主视觉理念）
- Typography stance（字体策略）
- Layout strategy（布局策略）
- Motion stance（动效策略）
- 不做什么（3 条以内）

## 允许的输入来源
- 用户口述（最常见）
- 已有页面/代码上下文
- 参考图/截图（MATCH 工作流）
