System Audit Use Cases
AI Product Design Director · UI/UX · Design System · Design Review

让 Cursor 在做设计时，先做判断，再做界面。

`premium-ui-design` 不是一个会产出同一种风格的 UI Prompt。它是一个总控设计 Skill：识别关键词、 判断平台、冻结输入、建立 Art Direction、吸收外部 Skill 方法论，最后统一跑审查。

开始使用 看案例 GitHub
流程统一。
结果不能同质化。
每个产品都应该有自己的判断与辨识度。
Design operating system

它把“做设计”这件事拆开，而不是把所有页面做成同一个模板。

Skill architecture

结构感不是装饰，它是这个 Skill 真正能持续工作的原因。

SKILL.md
定义触发词、工作流、平台判断、统一纪律。
skill-router.md
把不同平台的判断链路固定下来，避免每次乱跳。
design-audit.md
规定最后必须怎么审查，而不是“差不多就行”。
skill-registry.md
吸收外部 Skill 方法论，但不把首页做成列表目录。

专业 Cursor 案例（可复制）

从一句“页面普通/不够苹果风”开始，让总控先冻结输入，再路由到正确专家流程。

案例 1：Web NEW｜SaaS Landing Page 
使用 premium-ui-design 总控设计 Skill。

任务类型：NEW
平台：Web
产品类型：SaaS Landing Page（AI 产品）

目标：首屏 5 秒内让用户理解“我们做什么 + 为什么可信 + 下一步怎么做”（并明确 CTA）。

要求：
1) 先输出 Design Intelligence 卡（Product / Audience / Core task / density / visual focus / avoid）
2) 再输出 Art Direction（主视觉理念 + typography/layout/motion 策略 + 3 条 avoid）
3) 输出一页可落地结构：Hero + Proof + Features + Pricing teaser + FAQ + Footer
4) 覆盖默认/hover/disabled/loading/empty/error（以按钮/表单/弹窗为准）
5) Anti-AI Slop 自检：没有设计理由就移除（严重命中则直接否决）
6) 最后给出 100 分 Design Audit + Gate + 下一轮迭代计划
7) 工程建议：组件拆分、token 最小集、哪些不该动（禁止改业务逻辑）
案例 2：Web REDESIGN｜Dashboard 信息层级重构 
使用 premium-ui-design 总控设计 Skill。

任务类型：REDESIGN
平台：Web
产品类型：Dashboard（后台管理风格）

上下文：
- 我会给你当前页面截图/代码片段
- 直觉问题：信息层级不清、模块同构模板感、表格/筛选交互状态不完整

强制规则：
1) 禁止大改业务逻辑/数据结构/权限接口；只改 UI 结构、层级、组件状态与交互
2) 必须先做 AUDIT：给出必改项/可选项（按影响排序）再进入 REDESIGN
3) Anti-AI Slop：任何“圆角卡片堆叠/同构模板/无意义渐变/不可读淡色文案”需要否决或给出理由
4) 输出新信息架构 + 关键组件 state 表（Filters、Table、Empty/Error、Loading skeleton）
5) 最后输出 100 分 Audit + Gate + 最小改动清单（Next changes）
案例 3：iOS AUDIT+FIX｜SwiftUI Settings 苹果风 
使用 premium-ui-design 总控设计 Skill。

任务类型：AUDIT 然后 FIX
平台：iOS
框架：SwiftUI
场景：Settings 页面（表单、开关、选择器、危险操作）

输入：我会贴 Settings 的 SwiftUI 视图代码（或截图）

审查目标（必须覆盖）：
- Apple HIG 气质是否原生（不要把 Web/模板感搬进 iPhone）
- 第一眼/第二眼/下一步路径是否清晰（Primary attention / Secondary attention / Primary action path）
- 完整交互 state：Default、Focused、Disabled、Loading、Empty、Error
- 可访问性落地：Dynamic Type、VoiceOver 语义（说明 label/traits/可访问顺序）
- Motion：Level 1 + 少量 Level 2（默认禁用无意义夸张动效）

输出：
1) Design Intelligence 卡（缺什么先追问）
2) Art Direction（苹果风 + 不做什么）
3) 100 分 Design Audit + Anti-AI Slop 门禁
4) FIX：逐条给具体替换建议（哪些 Section/控件怎么改、按钮文案怎么改、间距怎么改）
5) 工程实现建议：token 最小集、组件拆分、哪些不该动
Router principle

总控 Router 的作用，不是替你选一个漂亮风格，而是替你先做设计判断。

你只需要表达“这个页面感觉普通/不够高级”，总控会先做设计情报卡，再路由到正确工作流，并把专家 Skill 的原则嵌入最后的实现建议与审查评分。

一个真正能用的设计 Skill，不应该把所有产品做成同一种风格，而应该用同一套标准流程，做出不同产品各自该有的样子。
把设计审美变成一套可复用、可审查、可迭代的工作流。
从一句“这个页面不好看”开始，到最后一轮审查结束，所有步骤都有纪律。
